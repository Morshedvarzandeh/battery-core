# Fick's first law (lesson page)

`https://learn.lemonergy.com/transport/ficks-first-law/`

Teaches `J = −D dc/dx` with SI units, the sign convention, a worked
battery-material example, where diffusion shows up in a cell, and what the law
does not model. The flux calculator mirrors `ficks_first_law_flux`, including
its input rules, and `tests/test_lessons.py` checks the printed worked examples
against the Python. The source documentation is `docs/diffusion/ficks_laws.md`
and the notebook is `notebooks/transport/ficks_first_law.ipynb`.
